# CRM Millwater

Мобильное приложение (Flutter) для компании по доставке питьевой воды в капсулах.
Текущий этап — **UI по макету на моковых данных** (админ-часть). Бэкенд подключается позже
без переписывания UI (см. «Интеграция с сервером»).

## Запуск

```bash
flutter pub get
flutter run              # на подключённом устройстве/эмуляторе
flutter run -d chrome    # в браузере
flutter test             # тесты (сид-данные + smoke-тесты вкладок)
flutter analyze          # статический анализ
```

## Стек

- **Flutter** + Material 3, шрифт **Inter** (`google_fonts`)
- **flutter_bloc** (полный BLoC: события + состояния) — управление состоянием
- **equatable** — сравнение состояний/моделей
- **intl** — форматирование дат

## Архитектура (feature-first)

```
lib/
  app/            тема, токены (цвета/отступы/типографика), корневой виджет
  core/
    utils/        форматтеры денег, инициалы, цвет аватара, склонения
    widgets/      библиотека переиспользуемых виджетов (баррел: widgets.dart)
  data/
    models/       Driver, Customer, DeliveryRoute, ReportsSummary + enum-ы (fromJson/toJson)
    mock/         сид-данные (выверены под цифры макета)
    repositories/ CrmRepository (интерфейс) + MockCrmRepository (in-memory)
  features/
    home/         оболочка с нижней навигацией (4 вкладки)
    routes/       Маршруты: список → карточка → завершение доставки
    drivers/      Водители: список/поиск → детали → формы + удаление
    customers/    Заказчики: список/поиск → детали → формы + удаление
    reports/      Отчёты: stat-карточки, недельный бар-чарт, должники
```

Каждая фича: `bloc/` (Bloc + Event + State) + `presentation/` (страницы и виджеты).
BLoC зависит от **интерфейса** `CrmRepository`, а не от реализации.

## Данные и бизнес-правила

- Продукт — вода в **капсулах** (19 л), цена **20 000 сум/капсула** (`CrmRepository.capsulePrice`).
- Долг/предоплата и агрегаты отчёта считаются из текущего состояния репозитория.
- «Сегодня» в моках зафиксировано на 05.07.26 — под шапку макета.
- Данные живут в памяти в рамках сессии (без персиста).
